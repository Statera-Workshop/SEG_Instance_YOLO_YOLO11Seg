# SEG_Instance_YOLO_YOLO11Seg

**YOLO11-seg - instance segmentation (YOLO) - training and test evaluation**

Part of the *Physical AI Segmentation* reference series of the **Statera Working Group**:
one model per repository, the same data, protocol and metrics for every model - only the model differs.
The data are the FashionLetters36 images of the *Physical AI Object Detection* series (`OD_Image_*`) with masks,
so the results are directly comparable with the detection results.

## Model

- Paper: Ultralytics YOLO11 (2024), yolo11-seg
- Implementation source: ultralytics/ultralytics Segment / Proto / v8SegmentationLoss, reimplemented on the detection stage's YOLO11-n (unchanged)
- Parameters: 2.85 M (36 classes)

- YOLO11-n (detection stage)
- Proto on P3: 32 prototypes at stride 4 (64 channels)
- cv4 per level: 32 mask coefficients per anchor

Loss / assignment: v8 detection loss (TAL) + mask BCE (cropped, box-area normalised), gain 7.5 (= box gain)

Differences from the original (common protocol):

- No ImageNet weights, common init, no mean / std, 608 input, Adam 1e-4 constant, common augmentation (flip + YOLO-paper augmentation) and post-processing (see [Unified] markers)
- Ground-truth masks downsampled to prototype resolution (nearest)

## Data: FL36-Seg (synthetic, generated by step 1)

FashionLetters36 regenerated with the same seed plus masks: 36 classes = Fashion-MNIST (10) + EMNIST letters (26);
608 x 608 canvases with 3-10 non-overlapping objects of 32-160 px; 4,096 train / 1,024 test images, fixed seed -
every user generates the same dataset, and images and boxes are identical to FashionLetters36. A mask is the glyph
pixels brighter than 30, the same threshold that defines the boxes. Instance masks: SegmentationObject PNGs (value k = k-th XML object); boxes = tight boxes of the masks.

EMNIST is downloaded from NIST; if the download is refused, fetch `gzip.zip` in a browser from
https://www.nist.gov/itl/products-and-services/emnist-dataset and run
`python data_processing_fl36seg.py --emnist-zip <path>/gzip.zip`.

## Results

> **v1.1 (2026-11-08)** - KITTI-MOTS instance results added (section below, video-segmentation stage of the series) with their weights in Release v1.1. The FL36-Seg results, defaults and Release v1.0 are unchanged.

Test set: FL36-Seg test (1,024 images, 6,699 objects, 36 classes), after 30 epochs (0.5 h on an RTX 4070 Laptop GPU).

| | AP50 | AP75 | **AP50:95** | Recall (IoU 0.5) |
| --- | --- | --- | --- | --- |
| mask | 0.8257 | 0.5867 | **0.5189** | 0.891 |
| box | 0.8417 | 0.8410 | 0.8135 | 0.904 |

The comparison metric of the series is **mask AP50:95** (mean over IoU 0.50, 0.55, ..., 0.95): on FL36-Seg every correct box is also a correct mask at IoU 0.5, so AP50 saturates.
Semantic mIoU derived from the instances (score >= 0.5, incl. background): 0.6349. Inference: 47.6 images / s incl. post-processing and mask decoding.

Convergence (test AP50 every 5 epochs):

| Epoch | 5 | 10 | 15 | 20 | 25 | 30 |
| --- | --- | --- | --- | --- | --- | --- |
| mask AP50 | 0.561 | 0.691 | 0.753 | 0.763 | 0.797 | 0.826 |
| box AP50 | 0.565 | 0.703 | 0.765 | 0.775 | 0.813 | 0.842 |

Protocol: 30 epochs, Adam lr 1e-4 (constant), effective batch 8 (micro batch 2 x 4 accumulation), input 608, seed 777,
no pretraining; augmentation: horizontal flip + the basic YOLO-paper augmentation (random scale / translation 20 %,
HSV hue 0.1, saturation / exposure 1.5); test evaluation every 5 epochs.

## KITTI-MOTS (v1.1, video-segmentation stage)

`yolo11_seg_km`: the same YOLO11-seg, started from the MOT-stage `v11` detector (KITTI-MOTS train, 30 epochs, 1216 x 384) so
only the mask branch is new; trained on the KITTI-MOTS instance masks (car, pedestrian), wide canvas 1216 x 384, Adam
1e-4, seed 777. The fine-tuning length (8 epochs) was chosen on held-out TRAIN sequences (0004, 0015), never on val. Test = KITTI-MOTS val (9 sequences, 2,981 frames). Protocol difference to the FL36-Seg result
above: detector initialisation instead of training from scratch.

The three instance models of the stage:

| --- | --- | --- | --- | --- | --- |
| Mask R-CNN | 6 | 0.773 | 0.712 | 0.428 | 21.1 |
| Mask R-CNN | 20 (used by the MOTS rows below) | 0.766 | 0.727 | 0.469 | 20.6 |
| Cascade Mask R-CNN | 20 | 0.777 | 0.743 | 0.485 | 17.5 |
| YOLO11-seg | 8 | 0.705 | 0.639 | 0.358 | 33.8 |

Usage: KITTI images and KITTI-STEP as below, KITTI-MOTS instance PNGs from KITTI-STEP, VOC layout of the MOT stage,
then training from the MOT detector weights (Release v1.0 of `Statera-Workshop/MOT_Detectors_KITTIMOTS`):

```bash
mkdir -p ~/Physical_AI/datasets/downloads && cd ~/Physical_AI/datasets/downloads
wget -c https://s3.eu-central-1.amazonaws.com/avg-kitti/data_tracking_image_2.zip     # KITTI tracking images
wget -c http://storage.googleapis.com/gresearch/tf-deeplab/data/kitti-step.tar.gz      # KITTI-STEP labels
unzip -q data_tracking_image_2.zip 'training/image_02/*' -d ~/Physical_AI/datasets/KITTI_MOTS
tar -xzf kitti-step.tar.gz -C ~/Physical_AI/datasets/                                  # -> datasets/kitti-step
```

```bash
python tools/mot/step_to_mots_png.py          # -> datasets/KITTI_MOTS/instances (KITTI-MOTS encoding)
python tools/mot/kittimots_to_voc.py          # -> datasets/KITTI_MOTS_VOC (boxes, ignore regions, splits)
export UNIFIED_SEG_DATASET=kittimots UNIFIED_IMAGE_H=384
UNIFIED_INIT_CKPT=image_v11_kittimots_e030.pth python train_seg_yolo11_seg_km.py --epochs 8
python evaluate_seg_yolo11_seg_km.py --weights seg_yolo11_seg_km_kittimots_e008.pth
```

Weights: Release v1.1 (`seg_yolo11_seg_km_kittimots_e008.pth`).
KITTI / KITTI-MOTS / KITTI-STEP are CC BY-NC-SA 3.0 (non-commercial); the weights inherit it.

## Usage

```bash
pip install -r requirements.txt
python data_processing_fl36seg.py           # downloads Fashion-MNIST + EMNIST, generates FL36-Seg
python train_seg_yolo11_seg.py               # training, then test evaluation (runs/seg_yolo11_seg/)
python evaluate_seg_yolo11_seg.py            # test evaluation of runs/seg_yolo11_seg/checkpoints/ (or --weights <file>)
```

Data are expected under `$PHYSICAL_AI_ROOT/datasets` (default `~/Physical_AI/datasets`).
Smoke test: `python train_seg_yolo11_seg.py --epochs 1 --max-train 8 --max-test 4`.

Trained weights: the GitHub Release of this repository contains `seg_yolo11_seg_fl36seg_e030.pth` (the run reported above).
Put it into `runs/seg_yolo11_seg/checkpoints/` or pass `--weights <file>` to the evaluation script.
Demo scripts using these weights will be added in a later release.
